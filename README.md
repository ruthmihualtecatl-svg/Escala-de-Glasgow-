# Escala de Glasgow

Herramienta interactiva para registrar las respuestas ocular, verbal y motora, calcular el puntaje total e indicar su rango orientativo.

Abre `index.html` en un navegador. No requiere instalación ni conexión a internet.

La interpretación mostrada es leve (13–15), moderada (9–12) y grave (3–8). En la respuesta motora se distinguen retirada (4) y flexión anormal (3), según la puntuación estándar. Esta herramienta no sustituye la valoración de un profesional de salud.
